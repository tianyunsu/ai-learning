起点 / 分开三个层次

你的直觉抓住了输出方式，但还缺少内部机制

“预测下一个 token”容易让人联想到手机输入法：根据刚出现的几个字，补一个常见词。但现代自回归语言模型预测时，会先让可见上下文经过多层计算，才得到下一个 token 的概率。

先做两个小校准

通常说的是大语言模型。token 不等于一个词：它可能是字、词片段、数字片段或标点，取决于分词器。

人工智能与语言模型都早于 Transformer。Transformer 最初用于序列转换与机器翻译；本文聚焦基于它的自回归大语言模型。[1][2]

架构 ≠ 参数 ≠ 整个系统

架构决定有哪些计算部件；参数决定这些部件具体如何计算；系统还包括生成策略、计算预算与外部工具。

类比：同样的计算机指令集可以运行不同程序。神经网络的权重不是普通程序代码，但它们同样能改变输入到输出的计算映射。

“底层完全没变”并不准确。很多模型仍属于 Transformer 家族，但网络规模、注意力实现等可能变化；更关键的是，数据、权重、后训练目标与推理流程已经发生变化。

第一性原理 / 目标不是实现方法

若下一步答案由规则决定，准确预测就可以要求计算

把一个确定性任务写成 y = f(x)：x 是题目，f 是解题规则，y 是正确答案。假设训练标签完全正确，那么理想的条件分布可以把全部概率放在 f(x) 上。预测器要实现这种分布，可以把 f 的计算过程学进参数里。

理想目标：p*(y | x) = 1，当 y = f(x)；否则为 0。这是确定性、无噪声任务的理想化描述。实际模型只有近似分布；有限 logits 的 softmax 通常也不会给出严格的 0 或 1。
办法 A · 记忆

记住“407 + 586 = 993”

见过这个题，直接取出答案。换成一个没见过的组合，记忆本身就不够了。

办法 B · 泛化

学会“逐位相加并进位”

下一步输出由当前两位数字与进位决定。可以应用到新的数字组合；但学得是否稳定、能否推广到更长数字，仍须测试。

两种办法都能降低训练误差。因此，预测目标允许学出算法，却不强制模型只学算法。真实模型可能混合记忆、启发式和可泛化的计算。不能只看答对一道题，就判定它采用了哪一种。

稍深一点：语言模型究竟优化什么？
L(θ) = − Σₜ log pθ(zₜ | z₁, …, zₜ₋₁)
pθ(z₁, …, zₙ) = ∏ₜ pθ(zₜ | z₁, …, zₜ₋₁)

第一行是典型的自回归预训练损失：训练让真实 token 的概率更高。第二行是概率的链式分解：任何序列分布都可以这样表示。这种分解并没有规定内部只能统计相邻词频。θ 表示学习到的参数，z 表示 token。训练时常用正确前缀和因果掩码，并行计算多个位置的损失；生成时才逐步追加新 token。[1][2]

正确的数学步骤、程序执行轨迹、论证关系都可以出现在训练序列中。能利用这些关系的内部计算，会获得有用的学习信号；但错误文本和捷径同样可能带来误导。

第一性原理 / 神经网络是一种计算装置

“只有矩阵乘法”并不等于“不能进行逻辑”

Transformer 不是一张固定的词频表。以下用常见的自回归 Transformer 作简化说明：[1]

① 输入表示token 转成向量，并注入位置信息。向量可承载符号、角色、关系等分布式特征。
② 注意力依据内容与位置，从可见上下文的表示中加权取信息。它是可学习的信息路由，不是搜索互联网。
③ 前馈网络通过线性变换与非线性函数，组合并变换当前表示；残差连接提供跨层信息通道，归一化调节数值尺度。
④ 重复多层同一次前向计算就能组合多步变换；各层参数通常不同。
⑤ 输出概率把最后的表示投影到词表，得到 logits，再经 softmax 成为概率，按解码策略选下一个 token。
Attention(Q,K,V) = softmax(QKᵀ / √dₖ + M)VQ：当前位置的查询；K：用于匹配的键；V：被汇聚的信息；M：因果掩码。Q、K、V 都由向量经过学习到的投影产生，不能简单等同于人类的“问题、关键词、答案”。

直观上，注意力可以把“相关输入”送到同一个计算位置，前馈网络再组合它们。以下构造说明：简单的神经网络运算，确实能够表示精确的逻辑规则。这只是表达能力的证明，不是宣称真实模型必然按这个电路工作。

交互实验 · 逻辑门

一个非线性，就能构造 AND 与 XOR

二值输入的精确构造

设 r(u) = max(0,u)，即 ReLU。点击切换 x、y，观察同一套公式如何输出逻辑结果。

AND(x,y) = r(x + y − 1)
XOR(x,y) = x + y − 2r(x + y − 1)
NOT(x) = 1 − x

仅对 x、y ∈ {0,1} 成立。把这样的局部规则组合起来，可以构造加法等有限计算。这不证明某个有限规模模型能处理任意长度问题，也不保证训练能自动找到该构造。

第一性原理 / 输出序列可以成为工作区

逐个输出，并不会阻止执行一个完整算法

想象把竖式加法写成一个状态机。每步只做小任务：读两位数字和旧进位，写下结果位与新进位，再处理下一列。完整答案来自这些局部更新的组合，而非一次性猜出整个数字。

sᵢ = aᵢ + bᵢ + cᵢ
dᵢ = sᵢ mod 10　　cᵢ₊₁ = ⌊sᵢ / 10⌋从个位向高位处理，初始进位 c₀ = 0。每一列的局部输入只有两位数字与一个进位；当前进位和已写结果足以支持下一步。
交互实验 · 从个位开始

把“计算”拆成可连续预测的下一步

本实验是人工编写的确定性加法器，不是真实语言模型。它证明“按序列输出”与“执行算法”兼容，不衡量模型能力。真实分词也未必把每个数字分成一个 token。

已处理列：0
下一列进位：0
当前已写低位：—

支持各至多 18 位的非负十进制整数；验证总和使用 BigInt，避免浮点整数精度损失。改变输入后，请点“载入题目”。

同一次计算里的深度

生成一个 token 前，多层 Transformer 已执行许多向量变换。一个输出单位背后，可以有大量内部计算。

多次生成形成的深度

新步骤写回上下文，后续生成可以读它，再计算下一步。这形成了“读 → 算 → 写 → 再读”的外层循环。

所以，“架构不是 RNN”不代表整个生成过程没有循环：自回归生成在网络外部反复调用同一个模型。草稿区与思维链可以把中间状态显式保留下来，帮助某些多步任务。[3][4]

中间步骤不是免费的，也不总有益：每次追加都需要计算，错误还可能传到后面。通常生成时模型权重不更新；改变的是上下文与缓存。更长的过程提供更多计算机会，却不保证更正确。

从算术到推导 / 用规则变换符号

公式推导，是带适用条件的状态更新

算术更新数字，代数更新表达式。题目、当前公式与假设共同决定哪些变换合法；模型可以学习选择变换并生成新表达式。真正成立的推导，还要求每一步满足数学规则。

交互实验 · 配方法

从 ax² + bx + c = 0 推出求根公式

假设 a、b、c 为实数且 a ≠ 0；要在实数范围开方，还需判别式 Δ ≥ 0。以下是预先写定并核验的推导，点击观察当前公式与允许操作的对应关系。

ax² + bx + c = 0起点：确认 a ≠ 0，才能把两边除以 a。
x² + (b/a)x = −c/a两边除以非零的 a，再移项；这是等价变换。
x² + (b/a)x + b²/(4a²) = −c/a + b²/(4a²)两边加同一个量，把左边凑成完全平方。
(x + b/(2a))² = (b² − 4ac)/(4a²)使用平方展开恒等式，并通分右侧。
x + b/(2a) = ±√Δ / (2|a|)Δ = b² − 4ac。若 Δ ≥ 0，实数开方必须保留 ±；√(a²) = |a|。
x = (−b ± √Δ) / (2a)移项。a 为负时符号标签会互换，但 ± 表示的根集合相同。Δ = 0 时两根重合；Δ < 0 时无实根。

例如 x² − 5x + 6 = 0 的判别式是 1，所得根为 2、3；代回分别得到 4 − 10 + 6 = 0 与 9 − 15 + 6 = 0。“生成一个看似合理的公式”与“验证这个公式等价”是两个不同环节。

逻辑推理也有相同结构：从“所有 A 都属于 B”与“u 属于 A”，可得“u 属于 B”；若只是“多数 A 属于 B”，就不能必然推出同一结论。模型必须保留量词与前提，不能只匹配句子外形。

这也回答“新公式怎么可能被预测”：学到的通用变换，可以在未见过的符号组合上生成新表达式。新颖不必来自记忆原句，但要证明一次具体输出确实可靠，仍需核验。

成长路径 / 骨架相近，学习与运行方式可以不同

为什么能力提升，不需要先发明一种全新架构？

改变的层次如何帮助推理它不保证什么
预训练的数据、规模与权重更多任务结构与足够的表示能力，让模型有机会学到跨题目的关系和计算规律。上下文示例也能改变当前任务的行为。[2]更大不自动等于更正确；记忆、捷径与错误规律仍可能存在。
步骤示范与监督训练示范把问题分解、执行局部规则、组织答案；训练中间步骤可改善某些多步计算。[3]学会推导文风，不等于每步都合法。
强化学习等后训练用可验证答案等奖励信号，增加成功策略的生成倾向；DeepSeek-R1 系列提供了公开的研究实例。[5]奖励存在局限；也不能推出所有模型都使用相同流程。
推理阶段的计算预算生成更多中间步骤，或产生候选、检查与筛选，让系统有机会修正初始路径。[4][5]多写、反思或多采样都没有普遍的正确性保证。
外部执行与验证工具模型把问题转成程序，由解释器执行；或交给符号系统、证明检查器核验。[7]工具能准确执行错误程序。题目理解与调用参数仍需检查。

尤其要区分：输出仍可逐 token 生成，但后训练不一定只优化“下一个 token 的交叉熵”。强化学习可以依据完整回答的奖励更新参数。输出形式保留，并不等于训练目标没有改变。

模型内部完成

数值或公式由神经网络的生成过程直接产出。它可能运用学到的规则，也可能出错；最终答案需要独立检查。

整个系统完成

模型生成代码或工具调用，外部执行器负责计算，模型再解释。整数或符号运算可以提供精确结果；浮点计算仍有精度限制。看到正确计算时，应先问清是哪一层完成的。

能力边界 / 容许计算，不等于保证正确

为什么会推理，仍然会算错、编造或自相矛盾？

训练信号不等于真理判定器

预训练奖励对文本的预测，不直接保证文本真实或推导有效。一个流畅、常见的错误，也可能被赋予高概率。

学到的是有限能力

有限参数、上下文、数值精度与生成预算限制了计算；任务变长、表达方式改变或超出训练分布时，规律可能失效。

错误可以沿步骤传播

某一列进位错了，后面的计算可能在错误状态上继续。更长推导增加计算空间，也增加犯错机会。

文字说明不是内部过程的完整记录

可见思维链可能帮助解题，但也可能合理化一个已有倾向。研究发现，一些解释会遗漏真正影响答案的偏置信号。[6]

怎样区分“会背答案”与“学到可泛化规则”？

测试新组合，改变符号名称与题目措辞，检查连续进位、非零除数等边界，再测试更长输入。对计算，使用独立执行器或反算；对证明，检查每步等价与适用条件，必要时使用形式化证明检查器。通过这些检查能提供能力证据，但单凭输出仍不能完全还原内部机制。

预测与推理的联系是：
为了预测下一步，可以先计算下一步；把下一步写下来，又能成为后续计算的输入。

因此，不存在“先做词语预测，后来突然跳出 Transformer 去做逻辑”的必然断裂。相近的计算骨架，学习到不同参数、配合不同训练与运行流程，可以承载不同能力。它的推理表现需要用任务与验证来判断，而不是由“预测器”这个名字决定。
